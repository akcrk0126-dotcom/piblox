# 로켓 카트

로켓 타고 달리는 3D 멀티 레이싱 게임 (브라우저 · PC · 폰).

## 핵 방지 구조
- 브라우저는 **입력만** 보내요 (조향 · 가속 · 브레이크 · 드리프트 · 아이템 버튼).
- 위치 · 속도 · 충돌 · 아이템 · 바퀴 수 · 순위 · 기록은 **전부 서버가 계산**해요.
- 서버는 1틱에 입력 1개만 처리해서 속도 핵이 안 되고, 값은 범위를 검사해요.
- 기록판은 서버만 써요.

## 실행
```
npm install
npm start          # http://localhost:8080
```
Railway 에서는 `npm start` 로 그대로 돌아가요 (PORT 환경 변수 사용).
piblox 저장소 안에 있으니 Railway 서비스의 Root Directory 를 `rocketkart` 로 잡아 주세요.

## 온라인 (서버 없이, Firebase)
`/health` 서버가 없으면 piblox 의 Firebase 로 온라인 방을 열어요. **방을 만든 사람 브라우저가 서버 역할**(같은 `server/game.js` 로 판정)을 하고,
손님은 입력만 보내요. 경로는 `playhub_mp/rooms/rk_<코드>/players/<uid>` (각자 자기 칸에만 씀), 빠른 시작 목록은 `rk_list`.
- 빠른 시작: 대기 중인 공개 방에 들어가고, 없으면 새 공개 방을 열어요 (12초 뒤 출발).
- 방 만들기 / 코드 참가: 코드로 모여요. 없는 코드로 참가하면 그 코드로 방을 만들어요 (허브 초대 링크 `?room=` 도 같은 방으로).
- 방장이 나가면 방이 끝나요.

## 혼자 달리기 (서버 없이)
서버(`/health`)가 없으면 메뉴에 **혼자 달리기**만 보이고, 방 코드(`server/game.js`)를 브라우저 안에서 그대로 돌려 봇 7대와 달려요.
piblox 허브용 정적 버전은 이렇게 다시 만들어요:
```
npm run static     # ../rocket 폴더를 새로 만듦
```

## 구조
- `shared/rk.js`: 트랙 · 차 물리 (서버와 브라우저가 같이 씀)
- `server/game.js`: 방 · 레이스 · 아이템 · 봇
- `server/index.js`: 웹 서버 + 실시간 연결
- `public/`: 화면 (Three.js)
- `tools/static.js`: 서버 없이 도는 정적 버전 만들기

## 맵 (8개)
네온 시티 · 토성 링 웨이 · 용암 협곡 · 정글 폭포 유적 · 빙하 크레바스(미끄러움) · 사이버 하이퍼튜브(회전) · 사막 메가 점프 · 레인보우 은하(벽 없음)

## 지름길 · 부스터
맵마다 1~2개 지름길이 있어요. 노란 `지름길 ▶▶` 표지판 쪽 끝 차선으로 붙어서 갈라지는 곳을 지나면 들어가요 (`shared/rk.js` 의 `cuts`).
부스터 판은 맵마다 9~11개.

## 니트로
드리프트 · 점프 묘기 · 아슬아슬 추월 · 슬립스트림으로 게이지를 채워 `Q` 로 폭발 가속.
