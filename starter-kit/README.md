# 🎮 piblox 스타터 키트

piblox 허브에서 꾸민 **아바타 · 채팅 · 이모트**가 그대로 들어간 게임을 만드는 출발점이에요.
`starter.html` 하나만 고치면 내 게임이 돼요.

## 시작하기

1. **폴더 옮기기:** 이 폴더(`starter.html`, `README.md`, `CLAUDE.md`)를 **내 GitHub 저장소**에 넣어요.
2. **설정 바꾸기:** `starter.html` 맨 위 설정 3줄을 바꿔요.
   - `GAME_ID` — 내 게임 이름(영어 소문자). 예: `'zombierun'`
   - `GAME_TITLE` — 화면에 보일 제목. 예: `'🧟 좀비 런'`
   - `PIBLOX_SITE` — piblox 사이트 주소(주인에게 물어보기)
3. **실행해 보기:** 내 컴퓨터에서 `python3 -m http.server` 실행 → 브라우저에서 `http://localhost:8000/starter.html`
4. **올리기:** 다 만들면 GitHub Pages 같은 곳에 올리고, 주소를 piblox 주인에게 알려줘요. 허브에 내 게임이 걸려요.

## 이미 들어 있는 것

- 허브에서 꾸민 그대로의 로블록스식 아바타, 걷기·점프 동작, 이름표
- 3인칭 카메라, WASD/Space, 모바일 조이스틱
- 블록 쌓기 도구 `block(...)`, 스터드 무늬 재질, 간판, 로블록스 기본 색
- 멀티플레이: 같은 방 사람끼리 서로 보여요 (`?room=이름`으로 친구끼리)
- 채팅(`/` 키), 이모트(`.` 키나 💃 버튼) — 플랫폼이 자동으로 붙여 줘요
- 예시 맵: 계단 코스, 밟으면 처음으로 가는 빨간 블록, 동전 10개

## 어디를 고치나요?

`starter.html` 안 **"🛠 여기서부터 내 게임"** 부분이에요.

| 함수 | 하는 일 |
|---|---|
| `buildWorld()` | 맵 만들기 — `block(x, y, z, 가로, 높이, 세로, 재질)`로 블록을 쌓아요 |
| `gameTick(dt, t)` | 매 순간 실행 — 규칙, 점수, 함정 |
| `onOthersChanged()` | 다른 사람이 들어오거나 나갈 때 |
| `myExtraData()` | 다른 사람에게 같이 보낼 내 정보(점수 등) |

## 꼭 지킬 것

- `multiplayer.js`는 piblox 주인 파일이에요. 고치거나 복사하지 말고 주소에서 불러 쓰기만 해요.
- 샤드, 레벨, 마켓 아이템 같은 플랫폼 보상은 건드리지 않아요. 게임 안 점수와 코인은 마음대로 만들어도 돼요.
- 방 이름과 랭킹 이름은 자동으로 `ext_내게임ID_`로 시작해요. 다른 게임과 안 섞여요.
