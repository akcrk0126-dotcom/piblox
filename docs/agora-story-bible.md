# 아르카디아 연대기 — 「가시와 룬의 노래」 (스토리 바이블)

모든 지역 · 랜드마크 · 몬스터 · 보스 · 레이드가 **하나의 이야기** 안에서 이유를 갖게 하는 설정서예요.
콘텐츠(`lore/*.js`)와 구현(`agora-towns.js` · `agora-saga.js` · `agora-rpg.js`)은 이 문서를 기준으로 해요.

## 1. 역사 (천 년 전 → 지금)

1. **룬의 왕국 아르카디아** — 천 년 전, 거인의 고원 위 왕도에 **오르비안 왕**이 다스리는 룬의 왕국이 있었다. 사람들은 돌과 바람과 물에 룬을 새겨 함께 살았다.
2. **검은 별이 떨어진 밤** — 북쪽 하늘에서 검은 별이 떨어졌다 (지금의 **가시 심장**). 별에서 자라난 **검은 가시**는 생명과 룬을 먹고 자라며, 닿는 생물을 미치게 했다.
3. **가시 전쟁** — 왕국은 거인족과 **여섯 수호수**와 손잡고 싸웠다.
   - 거인족의 영웅 **아르곤**은 붉은 협곡에서 가시 군세를 막다 쓰러졌다 (**거인의 유해**). 그의 아들 **그라녹**은 돌이 되어 아버지 곁을 지켰다.
   - 왕은 아르곤을 기려 고원에 **거상**을 세웠다 (지금은 **부서진 거상**).
4. **대봉인** — 궁정 현자이자 첫 번째 룬 지기 **세렌**은 가시를 땅속에 가두는 **대봉인**을 만들었다.
   - 여섯 지역에 **룬 수호석**을 박고, 각 수호석을 **수호수**가 지키게 했다.
   - 봉인의 마지막 룬은 대륙에서 가장 높은 **하늘 끝 봉우리**에 새겼다.
   - 대봉인을 짓느라 숲의 **세계수**를 베어야 했다 (지금의 **거인의 그루터기**). 세계수의 심장만은 가시 심장 위에 덮어 뿌리째 눌렀다.
5. **잊힌 왕국** — 봉인에 모든 힘을 쏟은 왕국은 시들었다. 왕은 성채에서 잠들었고, 사람들은 남쪽으로 흩어져 이야기를 잊었다.
   - 남은 것은 동요 · 전설 · 폐허뿐이다. **새싹 마을**은 그 후손들이 세운 마을이다.
6. **지금** — 천 년이 지나 봉인이 닳았다.
   - 북풍을 타고 **검은 씨앗**이 남쪽까지 날아오고, 수호수들이 하나둘 가시에 물들어 미쳐 가고 있다. 몬스터가 "들떠" 사납고, 보스와 레이드 보스가 나타나는 이유가 이것이다.
   - 룬 지기 **엘드라**(세렌의 마지막 제자의 제자)는 이것을 알아챘다. 그리고 룬진을 타고 온 플레이어 **"이름 없는 자"** 가 룬에 응답한다는 걸 알게 된다. 플레이어는 손으로 룬을 다시 새길 수 있는 사람이다.

## 2. 여섯 수호수와 룬 수호석

| 지역 | 수호수 (가시에 물든 모습) | 수호석 자리 | 맞붙는 방식 |
|---|---|---|---|
| 초록 언덕 | 풀빛 왕슬라임 「말랑대왕」 — 들판의 장난꾸러기 수호수 | 바람개비 언덕 (풍차가 수호석 위에 세워졌다) | 필드 보스 `fb_slime` |
| 속삭이는 숲 | 버섯대공 「포자왕」 — 세계수 그루터기의 버섯 군주 | 거인의 그루터기 한가운데 | 필드 보스 `fb_chief` |
| 은빛 호수 | 호수의 주인 — 천 년 산 은빛 물고기 (낚시 전설) | 호수의 정자 (섬) | 이야기 보스 「검은 물의 망령」(saga) + 정화 후 호수의 주인 등장 연출 |
| 안개 늪 | 늪의 왕 그롬 — 물의 여신 신전을 지키던 두꺼비 | 가라앉은 신전 깊은 곳 | 레이드 `grom` (중간에 필드 보스 `fb_queen` = 신전 꿀 제단의 여왕벌) |
| 붉은 협곡 | 바위 거인 그라녹 — 아르곤의 아들 | 버려진 광산 바닥 | 레이드 `granok` (중간에 필드 보스 `fb_tusk` = 거인의 탈것이던 엄니왕) |
| 서리 봉우리 | 서리 거룡 크라이오스 — 가시의 뿌리를 얼려 붙잡은 용 (용의 등뼈 능선은 그 몸이 굳은 것) | 얼어붙은 제단 | 레이드 `cryos` |

- 거인의 고원에는 수호석이 없다. 대신 **세렌의 기록**이 있다. 고원 장은 "왜 · 어떻게"를 밝히는 역사 추적 장이다. 이야기 보스 「왕좌의 수호 골렘」(saga)이 왕의 무덤을 지킨다.
- 검은 가시 침식지는 **가시 심장**이다. 세계수의 심장이 가시에 먹혀 **가시 군주**(`fb_treant`)가 되었다.

## 3. 장 구성 (메인 스토리) — 지역마다 한 장

각 장은 정착지 → 이상한 일 → 원인 추적 → 수호수와 대결 → 수호석에 룬을 다시 새김(정화) → **세상이 바뀜** 의 흐름이에요.
퀘스트 id 는 `c<장>_<번호>` (예 `c1_3`). 레벨은 지역 레벨대를 따라요.

| 장 | 지역 | 제목 | 핵심 사건 | 장이 끝나면 세상이 바뀌는 것 |
|---|---|---|---|---|
| 서장 | 새싹 마을 | 북풍의 씨앗 | 촌장 하몬이 밭에서 주운 **검은 씨앗**. 룬 지기 엘드라의 편지: "씨앗이 보이면 이름 없는 자를 보내라." 마을 사람들과 인사 · 첫 장비 | 마을 게시판에 엘드라의 편지가 붙어요 |
| 1 | 초록 언덕 | 멈춘 바람개비 | 볕드는 농원의 밭이 검게 썩고, 바람개비 언덕의 풍차가 멈췄다 (바람이 수호석의 룬을 돌려 왔는데 멈춤). 슬라임이 부풀어 오른다 → 검은 씨앗 수거 · 풍차 톱니 찾기 · 말랑대왕 진정 · 수호석에 룬 새기기 | 풍차가 다시 돌아요 · 검게 썩은 밭이 초록으로 · 제피의 글라이더 |
| 2 | 속삭이는 숲 | 세계수의 그루터기 | 잎새 마을의 숲지기들. 속삭임은 나무 정령들의 경고. 사냥꾼 로완의 여동생 **리나**가 요정의 버섯 고리 근처에서 실종 → 단서 추적 (발자국 · 찢긴 망토 · 리나의 일기) → 고목 뿌리 터널에서 구출 → 버섯대공 · 그루터기 수호석 | 숲의 포자 안개가 걷히고 나무 정령 불빛이 돌아와요 · 리나가 잎새 마을로 돌아와요 |
| 3 | 은빛 호수 | 호수의 주인 | 물안개 나루의 어부들: 물고기가 사라지고 물이 검어진다. 하얀 갈기 폭포에서 검은 물이 흘러든다 (북쪽 침식지에서 내려오는 물). 등대지기 할머니의 전설 → 오염원 세 곳 정화 → 「검은 물의 망령」 → 호수의 정자 수호석 → 호수의 주인이 수면 위로 뛰어오른다 | 호수 물빛이 맑아지고 · 전설 물고기를 낚을 수 있어요 |
| 4 | 안개 늪 | 가라앉은 신전 | 갈대 말뚝 마을은 반쯤 물에 잠겼다. 늪지 마녀 모르가나는 사실 물의 여신 신전의 마지막 무녀. 가시의 첫 뿌리가 신전 밑을 뚫어 신전이 가라앉았다 → 신전 꿀 제단의 여왕벌 (필드 보스) → 해독 · 신전 문 열기 → 레이드 「늪의 왕 그롬」 | 늪의 안개가 옅어지고 · 말뚝 마을에 등불이 켜져요 |
| 5 | 붉은 협곡 | 거인의 아이 | 붉은 먼지 광산촌. 감독관 **바르크**가 룬 광석에 눈이 멀어 광산 바닥을 파다가 그라녹을 깨웠다. 너구리 도적단이 광석을 털고, 엄니왕이 협곡을 휩쓴다 → 거인의 유해에서 아르곤의 이야기 (울음바위 = 아들의 눈물) → 레이드 「바위 거인 그라녹」 — 쓰러뜨린 뒤 그라녹은 다시 아버지 곁의 돌이 된다 | 광산촌에 활기 · 울음바위의 눈물이 멈춰요 |
| 6 | 거인의 고원 | 잊힌 왕국 | 별지기 야영지의 학자 엘린과 발굴단. 고대 골렘들은 아직도 죽은 왕의 명령을 따른다 → 왕실 인장 찾기 · 성채 왕좌 · 왕의 일기 · 거상의 비문 · 관측소의 별자리 판 → 대봉인의 정체와 "마지막 룬은 하늘 끝 봉우리" 라는 사실 → 이야기 보스 「왕좌의 수호 골렘」 | 골렘들이 인장을 알아보고 길을 열어 줘요 (고원 골렘 일부가 덜 공격적) |
| 7 | 검은 가시 침식지 | 가시 심장 | 최전선 요새 「가시 파수대」. 엘드라와 왕국 후예 병사들이 침식을 막고 있다. 가시 들판 정화 · 망령 진혼 · 세계수 심장의 진실 → 필드 보스 「가시 군주」 → 가시의 뿌리가 서리 봉우리로 이어져 있다는 사실 | 침식의 문 앞 가시가 물러나요 |
| 8 | 서리 봉우리 | 서리의 맹세 | 서리 수도원. 은둔자 오크는 천 년 전 마지막 왕실 기사 (서리 거룡의 저주로 늙지 않는다). 얼어붙은 군대 · 용의 뼈 → 레이드 「서리 거룡 크라이오스」 (용을 쓰러뜨리는 게 아니라 가시에서 풀어 주는 것) → 하늘 끝 봉우리에서 세렌의 마지막 룬을 다시 새긴다 | 북풍이 맑아지고 · 에필로그: 새싹 마을 축제 |

## 5. 이야기를 보여 주는 장치 — `agora-saga.js`

- **장 시작 연출**: 그 장의 지역에 처음 들어가면 화면 위아래에 검은 띠가 생기고, 카메라가 지역을 훑어요. 그 위로 「제 N 장 · 제목」 카드와 3~5줄 내레이션이 타자기처럼 나와요 (건너뛰기 가능).
- **장 끝 연출**: 수호석을 정화하면 세상이 바뀌는 순간을 보여 주고 (풍차가 돌기 시작 등) 내레이션 2~3줄이 나와요.
- **룬 수호석**: 수호석 자리마다 빛 잃은 룬 비석이 있어요. 정화 퀘스트 중에 E → 룬 새기기 미니 연출(룬 획 따라 그리기 or 홀드) → BUS `cleanse` { id }.
- **읽을거리(석판 · 일기 · 편지 · 수배지 · 동요)**: 지역마다 6~8개. E → 양피지 창. 처음 읽으면 연대기에 기록되고 작은 EXP. BUS `read` { id }.
- **연대기 (Codex) 창**: 장 목록(진행도) · 모은 이야기 · 만난 인물 · 수호수. 메뉴 버튼 📖 + 키 **N**.
- **주민 NPC**: 정착지마다 4~7명. 이름 · 직업 · 성격이 있고, 장 진행(전 · 중 · 후)에 따라 대사가 바뀌어요. 일부는 곁가지 퀘스트를 줘요.
- **이야기 보스**: 필드 보스 · 레이드가 없는 장(호수 · 고원)의 클라이맥스 보스. 해당 퀘스트를 받으면 정해진 자리에 나타나요. BUS `storyBoss` { id, state:'dead' }.
- **세상의 변화**: 장이 끝나면 정해진 것들이 바뀌어요 (풍차 회전, 밭 색, 물빛, 등불, 가시 후퇴). `F.story.done(chapter)` · BUS `chapter` { n, state:'start'|'done' }.

### 퀘스트 형식 (agora-rpg.js 와 같아요)

```js
{ id: 'c1_2', kind: 'main', giver: 'teo', to: 'teo', lv: 2, name: '검게 썩은 밭', desc: '퀘스트 설명',
  intro: [['teo', '대사'], ['teo', '대사']],      // 받을 때
  o: [ 목표, ... ],
  mid: ['teo', '진행 중 말 걸면'],
  end: [['teo', '대사']],                          // 완료할 때
  rw: { xp: 1.0, gold: 120, items: [['hp1', 3]], gear: { s: 'wpn'|'arm'|'acc', il: 3, r: 1 }, title: 'id' } }
```

목표 종류:
- `{ t:'talk', npc, d, say:[[npc, 대사]...] }` · `{ t:'kill', key, n, reg, at:campId, d }` · `{ t:'gather', item:'herb'|'mushroom'|'ore'|'crystal', n, reg, d }`
- `{ t:'discover', id: landmarkId, d }` · `{ t:'fboss', key: 'kingSlime'|'chief'|'queen'|'tusk'|'treant', d }` · `{ t:'raid', id, d }` · `{ t:'fish', n, d }` · `{ t:'glider', d }`
- **새로**: `{ t:'read', id: readableId, d }` · `{ t:'cleanse', id: keystoneId, d }` · `{ t:'sboss', id: storyBossId, d }` · `{ t:'reach', c:[x, z], r, d }` · `{ t:'collect', id: 'sp_…', n, d }` (이야기 물건 줍기: setpiece 중 `pickup` 계열)
- `giver` / `to` / `npc` 는 WORLD.npcs id 또는 이 지역 resident id. 메인 퀘스트는 장 순서대로 이어져요 (서장 → 1장 → … → 8장).

## 7. 문체

- 대사는 인물마다 말투가 달라요. 하몬은 허허 웃는 할아버지, 로완은 짧고 무뚝뚝, 미라는 밝게, 모르가나는 비꼬지만 따뜻하게, 엘린은 신나서 말이 빨라요.
- 내레이션은 짧고 시적으로. 한 줄 40자 안팎.
- 몬스터가 "왜 사나운지" 를 늘 가시와 연결해요. 귀엽지만 들뜬 숲의 친구들이 가시에 물들어 화가 난 거예요.
- 유머는 조금씩, 무섭게 하지 않아요 (전체 이용가). 슬픈 이야기도 희망으로 끝나요.
